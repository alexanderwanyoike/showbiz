Using Showbiz

What do I need to generate?
For cloud models, add your own provider API keys in Settings. For local models, configure a compatible inference server and its model names. The local server runs separately.
Where are projects and credentials stored?
Projects and media live in the .showbiz file you save. API keys are separate from project files and are currently stored as plaintext in the device's local settings database.
Is Showbiz free?
Showbiz is open source under the MIT license. Cloud generation is billed by your chosen provider. Local inference uses your own server and hardware.
