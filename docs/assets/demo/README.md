# Website demo media

`coastal-observatory.png` is original artwork generated with the built-in image-generation tool on 1 November 2026 for the Showbiz website demo.

Prompt: A quiet cinematic 16:9 establishing shot of a remote coastal observatory at dusk. Small weathered concrete circular observatory perched on a rocky headland, warm amber windows, steel blue ocean and hazy distant cliffs, sparse coastal grasses, subtle film grain, painterly cinematic concept art with convincing architectural detail and restrained colors. No people, text, logos, watermark or interface.

The artwork was imported into an isolated Showbiz 1.0.4 project using the native project and media commands. `site/images/storyboard.png` and `site/images/bible.png` are unedited browser captures of the production renderer backed by those commands. No provider requests, generated videos or billing records were fabricated. The Bible estimate describes a possible next generation, not a charge for this imported picture.

The README and website share these screenshots. The app icon comes from `public/icon.svg`; `yarn icons:generate` produces the website favicons and README's `public/icon.png`. The social preview combines the current icon and captured storyboard with the product name and description.
